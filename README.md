# Tony Kim · personal site

A single-page static site. `index.html` holds everything, and photos live in `assets/`.

Every push to `main` publishes the site through GitHub Actions (`.github/workflows/pages.yml`). In the repo's Settings → Pages, set Source to "GitHub Actions" once.

The design source is the Claude Design canvas: https://claude.ai/artifact/KQWJfVs34VUaNZihXL22Tp
